What other people have shared:

🌟 Great result — Writing, Claude
I asked Claude to rewrite my research abstract in plain English for a non-academic audience. I gave it the abstract and said "imagine explaining this to a curious 16-year-old who reads the Guardian." The result was so good I used it almost verbatim in our university press release.

Insight: Giving it an explicit audience persona + a publication as a reference point was the key — vague instructions like "simplify this" gave mediocre results.
😤 Frustrating failure — Data analysis, ChatGPT
I uploaded a CSV and asked for a time-series analysis. It confidently described trends that were completely backwards — rising where my data clearly fell. When I pointed this out it apologised and then made the same mistake with different numbers.

Insight: Never trust AI-generated chart interpretations without checking manually. It seems to generate plausible-sounding narratives regardless of whether they match the actual data.
🤯 Unexpected — Coding, GitHub Copilot
Copilot autocompleted an entire function that I'd only named — and it was exactly right, including edge cases I hadn't thought of. But the same session it hallucinated an npm package that doesn't exist and I wasted 20 minutes trying to install it.

Insight: Copilot is shockingly good at "fill in a well-known pattern" and surprisingly bad at "tell me what library to use."
